# Requirements Traceability Matrix: 4.2.image-download.md

| Acceptance Criteria | Test Scenario (Given-When-Then) |
|--------------------|----------------------------------|
| 1. Download Image button is available on the QR Code Details page and "My QR Codes" page | **Given** an authenticated user owns at least one QR code, **When** they visit the QR Code Details page or the My QR Codes list page, **Then** a Download Image button (with format selector) is visible and interactive |
| 2. User can choose format: SVG or PNG (via query parameter or UI toggle) | **Given** a user is on the Details or My QR Codes page, **When** they select SVG or PNG from the format dropdown and click Download Image, **Then** the request is sent with the correct `format` query parameter and the file is downloaded in the selected format |
| 3. Image is generated on demand (not stored in database) | **Given** a user requests an image download, **When** the server handles the request, **Then** the image is generated at runtime from stored QR parameters and no image file or blob is persisted to the database |
| 4. Downloaded file has a meaningful filename (e.g., qrcode-{id}.svg or qrcode-{id}.png) | **Given** a user downloads a QR code image, **When** the browser saves the file, **Then** the filename follows the pattern `qrcode-{id}.svg` or `qrcode-{id}.png` matching the requested format |
| 5. Only the owner can download — unauthorized access returns 404 | **Given** an authenticated user attempts to download a QR code that belongs to another user, **When** the download request is processed, **Then** the response is HTTP 404 Not Found; the same applies for non-existent QR code IDs |
| 6. Content-Disposition header is set for download | **Given** a valid download request is made, **When** the server returns the image file, **Then** the response includes a `Content-Disposition: attachment` header causing the browser to download rather than display the file |
| 7. Image generation completes in under 1 second | **Given** a download request for any valid QR code, **When** the image is generated on the server, **Then** the response is returned within 1 second under normal operating conditions |
