## 2. Given-When-Then Mapping

| AC | Given | When | Then |
|----|-------|------|------|
| AC1 | Authenticated user on Dashboard | User clicks "Create QR Code" card or nav link | `/QRCodes/Create` loads with HTTP 200 |
| AC1 | Unauthenticated user | User navigates to `/QRCodes/Create` | Redirected to login page (HTTP 302) |
| AC2 | Valid 100-char alphanumeric `DecodedText` | Form is submitted | `ModelState.IsValid` = true; submission proceeds |
| AC2 | `DecodedText` = 101 chars or contains non-ASCII | Form is submitted | `StringLength` / regex validation error shown; nothing saved |
| AC3 | Create form loads | Page renders | ECC dropdown shows L/M/Q/H with M pre-selected |
| AC3 | Invalid ECC value sent via direct POST | Server processes request | `ModelState.IsValid` = false; 400 response |
| AC4 | Create form loads | Page renders | Version dropdown shows 1–10 with 5 pre-selected |
| AC5 | Notes = null | Form submitted with valid other fields | Submission succeeds; Notes stored as NULL |
| AC5 | Notes = 301 chars | Form submitted | `StringLength` validation error; nothing saved |
| AC6 | JavaScript disabled; POST sent with oversized `DecodedText` | Server handles request | Server-side `ModelState` rejects; form re-displayed with errors |
| AC6 | POST sent without CSRF token | Server handles request | HTTP 400/403 returned |
| AC7 | `DecodedText` = `"AAAAAAAA"`, ECC = H, Version = 1 | Form is submitted | User-friendly capacity error message shown on form; no 500 error |
| AC8 | Valid form submitted | Save succeeds | Browser redirected to `/QRCodes/Create?previewId={id}`; QR code image and Download PNG button visible |
| AC9 | Authenticated user submits valid form | `SaveChangesAsync()` called | DB row inserted with `UserId` matching authenticated user, `CreatedAt` in UTC |
| AC9 | Authenticated user A's `previewId` queried by user B | GET `/QRCodes/Create?previewId={n}` | No preview rendered (UserId ownership check); form shown blank |
| AC10 | POST save succeeds | Redirect issued | Browser lands on `/QRCodes/Create?previewId={id}` (200, not 404) |
| AC11 | Form rendered | Page loads | `__RequestVerificationToken` hidden input present in DOM |
| AC11 | POST submitted without CSRF token | Server validates | Request rejected (403) |
| AC12 | Valid QR code created | `SaveChangesAsync()` succeeds | Structured log entry written at `Information` level containing `UserId`, `QRCodeId`, `ECC`, `Version` |

## 3. Security Risk Traceability

| Risk ID | Risk Title | Mitigated By (Code) | Test Coverage |
|---------|-----------|---------------------|---------------|
| SEC-001 | UserId IDOR via form binding | No `UserId` in `CreateQRCodeViewModel`; always `User.FindFirstValue(ClaimTypes.NameIdentifier)` | 3.1-INT-002, 3.1-INT-012 |
| SEC-002 | Server-side validation bypass | `[Required]`, `[StringLength]`, `[RegularExpression]` on all fields; `ModelState.IsValid` gate; `[ValidateAntiForgeryToken]` | 3.1-UNIT-001–006, 3.1-INT-005–007, 3.1-UNIT-013 |
| SEC-003 | Regex bypass for ASCII constraint | Service-layer defence-in-depth regex in `QRCodeService.GenerateSvg()` | 3.1-UNIT-004–006, 3.1-INT-006 |
| TECH-001 | QR capacity overflow unhandled | `DataTooLongException` caught; version-capacity mismatch returns `(false, message)`; controller adds `ModelState` error | 3.1-UNIT-014, 3.1-INT-008, 3.1-INT-009 |
| TECH-002 | Third-party library integration risk | `IQRCodeService` abstraction; SVG encoded as base64 data URI removes GDI+/platform dependency | 3.1-INT-009, 3.1-INT-010, 3.1-INT-017 |
| TECH-003 | Redirect to non-existent Details route | Redirect goes to `Create?previewId={id}` (exists) rather than Story 3.3 Details route (not yet built) | 3.1-INT-014, 3.1-E2E-005 |
| DATA-001 | QR params saved without ownership FK | `QRCodeConfiguration`: `UserId` NOT NULL + FK to `AspNetUsers.Id` + cascade delete; `IX_QRCodes_UserId` index | 3.1-INT-011, 3.1-INT-013, 3.1-INT-018 |
| OPS-001 | Insufficient structured logging | `_logger.LogInformation(...)` with `{UserId}`, `{QRCodeId}`, `{ECC}`, `{Version}` | 3.1-INT-015, 3.1-INT-016 |

## 5. Deviations from Original Story

| # | Original Spec | Actual Implementation | Rationale |
|---|---------------|-----------------------|-----------|
| 1 | AC8: "preview displayed on page" (implied same-page inline) | Preview shown on Create page after POST-redirect-GET using `previewId` query param | POST-Redirect-GET prevents form resubmission on refresh; same user experience without double-submit risk |
| 2 | AC10: "redirect to QR Code Details page or My QR Codes list" | Redirects back to `Create?previewId={id}` | Story 3.3 (Details page) not yet implemented; temporary landing until 3.3 is built |
| 3 | Wireframe: "Download PDF button" | PNG download via JS canvas; no PDF | PDF export is Epic 4 (Story 4.1); PNG download added as useful interim capability |
