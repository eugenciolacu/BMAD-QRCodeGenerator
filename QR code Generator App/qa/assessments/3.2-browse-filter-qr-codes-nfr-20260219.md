## 1. Security

| Concern | Implementation | Status | Notes |
|---------|---------------|--------|-------|
| Authentication enforcement | `[Authorize]` on `QRCodesController` | ✅ Met | All actions require authentication; unauthenticated users redirected |
| CSRF protection | `[ValidateAntiForgeryToken]` on POST; `@Html.AntiForgeryToken()` in forms | ✅ Met | All state-changing requests protected |
| Data isolation | All queries filter by `UserId` from `User.FindFirstValue(ClaimTypes.NameIdentifier)` | ✅ Met | No cross-user data access; userId never taken from query |
| IDOR prevention | No user-controllable IDs in query; all actions scoped to current user | ✅ Met | Prevents access to other users' QR codes |
| Server-side input validation | ViewModel validation + `ModelState.IsValid` + EF Core constraints | ✅ Met | Invalid filter/sort input rejected; no over-posting |
| Parameterised queries | All DB access via EF Core LINQ | ✅ Met | No SQL injection risk |
| XSS prevention | Razor auto-encoding; no `Html.Raw` in table; Notes/content rendered safely | ✅ Met | No user input rendered unescaped |
| Rate limiting | Global fixed-window limiter (10 req / 10 s) in `Program.cs` | ✅ Met | Baseline DoS protection |
| Secrets management | DB connection string in `appsettings.json` | ⚠️ Gap | Should use User Secrets (dev) or environment variable/Key Vault (prod) |

## 2. Performance

| Concern | Implementation | Status | Notes |
|---------|---------------|--------|-------|
| Paginated queries | `.Skip((page-1)*pageSize).Take(pageSize)`; `pageSize=10` | ✅ Met | Efficient for user datasets; no full-table scan |
| Filtered search | All filters applied as EF Core `IQueryable` before `CountAsync`/`ToListAsync` | ✅ Met | No in-memory filtering; all server-side |
| Sorting | Dynamic sort via switch; whitelist on allowed columns | ✅ Met | No SQL injection; index on `CreatedAt` |
| Page load time | Table, filters, and pagination all server-rendered | ✅ Met | Sub-100ms for typical user |
| No N+1 queries | All data for page loaded in single query | ✅ Met | No per-row DB calls |
