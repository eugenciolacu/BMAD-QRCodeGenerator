## 3. Security Risk Traceability

| Risk ID | Risk Title | Mitigated By (Code) | Test Coverage |

| SEC-002 | Missing `[Authorize]` — Unauthenticated Access | `[Authorize]` applied at `QRCodesController` class level; inherited by `DownloadPdf` and all other actions; unauthenticated requests redirect to `/Identity/Account/Login` | 4.1-INT-015, 4.1-INT-016, 4.1-UNIT-005 |
| PERF-001 | PDF Generation Exceeds 1-Second AC Threshold | PNG generation is synchronous and in-memory; `PdfExportService` uses no I/O or network calls; `Document.Create(...).GeneratePdf()` returns `byte[]` in a single pass | 4.1-INT-012, 4.1-UNIT-004 |
| TECH-001 | QuestPDF License Not Registered at Startup | `QuestPDF.Settings.License = LicenseType.Community;` set at the top of `Program.cs` before `WebApplication.CreateBuilder(args)` — executes on every application start | 4.1-INT-017, 4.1-INT-018 |
| TECH-002 | SVG/PNG Embedding Produces Blank QR Code in PDF | `QRCodeService.GenerateImage()` generates PNG via `System.Drawing` from BMP bitmap; PNG returned as raw bytes; if generation fails (`success == false`) the action returns 500 before calling `GeneratePdf()`, preventing a blank-image PDF | 4.1-UNIT-002, 4.1-INT-003, 4.1-E2E-003 |
| SEC-003 | Information Disclosure via Differential Error Responses | Both "not found" and "not owned" paths execute identical code: `if (qrCode == null) return NotFound();` — single branch, single response, no distinction surfaced in the HTTP response | 4.1-INT-019, 4.1-INT-020 |
| AUD-001 | PDF Download Events Not Logged | Success: `_logger.LogInformation("QR code PDF downloaded. UserId={UserId} QRCodeId={QRCodeId}", userId, id)`; Failure: `_logger.LogWarning("DownloadPdf attempt failed. UserId={UserId} QRCodeId={QRCodeId} - not found or not owned", userId, id)` | 4.1-INT-021, 4.1-INT-022, 4.1-INT-023, 4.1-UNIT-006 |
| PERF-002 | Memory Pressure from Concurrent PDF Generation | `GeneratePdf()` returns a `byte[]` allocated per-request within QuestPDF's internal `MemoryStream`; no static or instance-level state retained; GC can collect after `File()` response is sent | 4.1-INT-024 |
| OPS-001 | Incorrect Headers — PDF Opens Inline | `return File(pdfBytes, "application/pdf", $"qrcode-{id}.pdf")` — third argument causes `FileContentResult` to emit `Content-Disposition: attachment`, not `inline` | 4.1-INT-006, 4.1-INT-013, 4.1-INT-014, 4.1-E2E-005 |
| DATA-001 | Stale or Incomplete PDF Metadata | `_context.QRCodes.FirstOrDefaultAsync(...)` loads the full entity; all four metadata fields (`DecodedText`, `ErrorCorrectionLevel`, `QRVersion`, `CreatedAt`) are model properties always present on the entity; null-safe rendering in `PdfExportService` | 4.1-UNIT-003, 4.1-INT-004, 4.1-INT-005 |

## 5. Implementation Details

### Route Implementation

| Route | Method | Controller Action | Implementation Status |
|-------|--------|-------------------|-----------------------|
| `/QRCodes/DownloadPdf/{id}` | GET | `QRCodesController.DownloadPdf(int id)` | ✅ Implemented |

### Data Flow

1. **User triggers download** — clicks "Download PDF" link on Details page, or selects a row and clicks "Download PDF" on the List page
2. **Browser issues GET** `/QRCodes/DownloadPdf/{id}`
3. **Authentication gate** — `[Authorize]` on controller class redirects unauthenticated requests to login; authenticated requests proceed
4. **Controller receives request**:
   - Extracts `userId` from `HttpContext.User.FindFirstValue(ClaimTypes.NameIdentifier)`
   - Queries database: `_context.QRCodes.FirstOrDefaultAsync(q => q.Id == id && q.UserId == userId)`
   - If `null` → log warning, return 404
5. **Image generation** — `_qrCodeService.GenerateImage(DecodedText, ECC, Version, "png")` → `byte[]`
   - If generation fails → log warning, return 500
6. **PDF generation** — `_pdfExportService.GeneratePdf(qrCode, imageBytes)` → `byte[]`
   - QuestPDF composes: header · image · divider · metadata table · page footer
7. **Logging** — `_logger.LogInformation("QR code PDF downloaded. UserId=... QRCodeId=...")`
8. **Response** — `return File(pdfBytes, "application/pdf", $"qrcode-{id}.pdf")`
   - Sets `Content-Type: application/pdf`
   - Sets `Content-Disposition: attachment; filename="qrcode-{id}.pdf"`
   - Browser triggers Save-As / auto-download

### Security Controls

| Control | Location | Purpose |
|---------|----------|---------|
| `[Authorize]` | `QRCodesController` class level | Authentication gate for all actions including `DownloadPdf` |
| Atomic ownership query | `DownloadPdf` action | IDOR prevention — single query with `id && userId` |
| `userId` from `HttpContext.User` | `DownloadPdf` action | Client cannot supply or forge the user identity |
| Identical 404 for not-found and not-owned | `DownloadPdf` action | Prevent record-existence enumeration |
| `QuestPDF.Settings.License = LicenseType.Community` | `Program.cs` startup | Prevents runtime `QuestPdfException` on first PDF generation |

### PdfExportService Layout Structure

| Layout Element | QuestPDF API | Content |
|----------------|-------------|---------|
| Page | `page.Size(PageSizes.A4)`, `page.Margin(2, Unit.Centimetre)` | A4, 2cm margins, Arial 11pt default |
| Header | `page.Header().Text(...)` | "QR Code Export" — 22pt, bold, dark grey |
| QR image | `col.Item().AlignCenter().Width(180).Image(qrImageBytes).FitWidth()` | Centred PNG, capped at 180pt |
| Divider | `col.Item().LineHorizontal(1).LineColor(...)` | Light-grey horizontal rule |
| Metadata table | `col.Item().Table(...)` | 2 columns (1:2 ratio); grey label background; 4 rows |
| Footer | `page.Footer().AlignCenter().Text(...)` | "Page N of M" in grey |
