## Security Review

| Check | Result | Notes |
|-------|--------|-------|
| `[Authorize]` on all controller actions | ✅ | Class-level attribute; no action accessible unauthenticated |
| `[ValidateAntiForgeryToken]` on POST | ✅ | CSRF fully mitigated |
| UserId never in ViewModel | ✅ | `CreateQRCodeViewModel` has no `UserId` field; SEC-001 fully mitigated |
| `ModelState.IsValid` before save | ✅ | Input cannot reach DB without passing server-side validation |
| Service-layer defence-in-depth regex | ✅ | Validates ASCII alphanumeric independently of model; SEC-002, SEC-003 mitigated |
| Notes XSS prevention | ✅ | Razor auto-encodes all `@code.Notes` output; no `Html.Raw` on user data |
| SVG XSS prevention | ✅ | SVG served as `data:image/svg+xml;base64,...` in `<img src>`; not injected as raw HTML |
| IDOR on `previewId` | ✅ | `saved.UserId == userId` ownership check before populating ViewBag |
| Parameterised DB queries | ✅ | All access via EF Core; no raw SQL |

## Risk Mitigation Confirmation

| Risk ID | Severity | Title | Mitigated | How |
|---------|----------|-------|-----------|-----|
| SEC-001 | Critical | UserId IDOR via form binding | ✅ | No `UserId` in ViewModel; always from `ClaimTypes.NameIdentifier` |
| SEC-002 | Critical | Server-side validation bypass | ✅ | `ModelState.IsValid` gate + `[ValidateAntiForgeryToken]` |
| SEC-003 | High | Regex bypass for ASCII constraint | ✅ | Service-layer regex independent of model binding |
| TECH-001 | High | QR capacity overflow unhandled | ✅ | `DataTooLongException` caught; version check; friendly error |
| TECH-002 | High | Third-party library integration risk | ✅ | `IQRCodeService` abstraction; SVG base64 data URI avoids GDI+/platform issues |
| TECH-003 | Medium | Redirect to non-existent Details route | ✅ | Redirects to `Create?previewId={id}` (exists); deviation documented |
| DATA-001 | High | QR params saved without ownership FK | ✅ | FK + NOT NULL + cascade delete in `QRCodeConfiguration` |
| OPS-001 | Medium | Insufficient structured logging | ✅ | `LogInformation` with `UserId`, `QRCodeId`, `ECC`, `Version` |
