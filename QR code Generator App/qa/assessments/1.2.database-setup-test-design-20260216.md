# Test Design: Story 1.2.database-setup

Date: 2026-02-16
Designer: Quinn (Test Architect)

## Test Strategy Overview

- Total test scenarios: 8
- Unit tests: 2 (25%)
- Integration tests: 4 (50%)
- E2E tests: 2 (25%)
- Priority distribution: P0: 3, P1: 3, P2: 2

## Test Scenarios by Acceptance Criteria

### AC1: ApplicationDbContext class is created extending IdentityDbContext
| ID                | Level       | Priority | Test                                                        | Justification                  |
|-------------------|-------------|----------|-------------------------------------------------------------|-------------------------------|
| 1.2-UNIT-001      | Unit        | P0       | Verify ApplicationDbContext inherits from IdentityDbContext  | Ensures correct base class     |
| 1.2-INT-001       | Integration | P1       | Validate DbContext registration in DI and app startup        | Ensures app can use context    |

### AC2: QRCode entity model is defined with all required fields
| ID                | Level       | Priority | Test                                                        | Justification                  |
|-------------------|-------------|----------|-------------------------------------------------------------|-------------------------------|
| 1.2-UNIT-002      | Unit        | P0       | Validate QRCode model properties and constraints             | Core schema validation         |
| 1.2-INT-002       | Integration | P1       | Create and save QRCode entity, verify persistence            | DB mapping and constraints     |

### AC3: Foreign key relationship is configured
| ID                | Level       | Priority | Test                                                        | Justification                  |
|-------------------|-------------|----------|-------------------------------------------------------------|-------------------------------|

| 1.2-INT-004       | Integration | P1       | Verify index exists on UserId in QRCodes table               | Performance, query optimization|

### AC4: EF Core migration is created and can be applied
| ID                | Level       | Priority | Test                                                        | Justification                  |
|-------------------|-------------|----------|-------------------------------------------------------------|-------------------------------|
| 1.2-E2E-001       | E2E         | P1       | Run migration, verify schema in SQL Server                   | End-to-end DB setup            |

### AC5: Database is created with all Identity tables and QRCodes table
| ID                | Level       | Priority | Test                                                        | Justification                  |
|-------------------|-------------|----------|-------------------------------------------------------------|-------------------------------|

## Risk Coverage
- SEC-001: Covered by 1.2-INT-001, 1.2-INT-003
- PERF-001: Covered by 1.2-INT-004
- DATA-001: Covered by 1.2-E2E-001, 1.2-E2E-002

1. P0 Unit tests (fail fast)
2. P0 Integration tests
