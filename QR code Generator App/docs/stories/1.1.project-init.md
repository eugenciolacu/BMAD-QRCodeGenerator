# Story 1.1: Initialize ASP.NET Core 10 MVC Project

## Status
Done

## Story
**As a** developer,
**I want** a properly initialized ASP.NET Core 10 MVC project with all required NuGet packages, configuration, and folder structure,
**so that** I have a solid foundation to build all application features.

## Acceptance Criteria
1. ASP.NET Core 10 MVC project is created with standard structure (Controllers, Views, Models, Services, Data folders)
2. Required NuGet packages are installed: Microsoft.EntityFrameworkCore.SqlServer, Microsoft.AspNetCore.Identity.EntityFrameworkCore, QuestPDF, Net.Codecrete.QrCodeGenerator, Serilog.AspNetCore
3. appsettings.json contains SQL Server connection string placeholder and app settings
4. Program.cs configures MVC, Identity, EF Core, and middleware pipeline
5. Global error handling middleware is configured (UseExceptionHandler for production, UseDeveloperExceptionPage for dev)
6. Structured logging is configured using Serilog
7. HTTPS redirection is enabled
8. Anti-forgery token validation is enabled globally
9. Application builds without errors and serves a basic landing page
10. _Layout.cshtml includes Bootstrap 5 CDN/local references per front-end spec
