# Story 5.6: Set PDF QR Code Image Size to 15 Centimetres

## Status
Done

## Story
**As a** user,
**I want** the QR code image in the exported PDF to be 15 centimetres wide,
**so that** it is large enough to be clearly visible and easily scannable when printed.

## Acceptance Criteria
1. The QR code image rendered in the exported PDF is exactly 15 cm wide
2. The image remains centred on the page
3. Aspect ratio is preserved (no stretching or distortion)
4. Metadata section below the QR code is unaffected
5. PDF still fits within A4 page margins without overflow

## Tasks / Subtasks
- [x] Update `PdfExportService.GeneratePdf` — change QR image width from `180` (pt) to `15` cm using `Unit.Centimetre`

## Dev Notes
### Technical Approach
- QuestPDF supports explicit units via overloads: `.Width(float size, Unit unit)`
- Replace `.Width(180)` with `.Width(15, Unit.Centimetre)` in `PdfExportService.cs`
- A4 usable width with 2 cm margins on each side = 21 − 4 = 17 cm, so 15 cm fits without overflow
