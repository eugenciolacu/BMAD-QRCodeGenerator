# Story 3.4: Delete QR Code

## Status
Done

## Story
**As an** authenticated user,
**I want** to delete a QR code I no longer need,
**so that** I can keep my QR code list organized and clean.

## Acceptance Criteria
1. Delete action is available from the QR code details page and list page
2. Deletion requires confirmation (e.g., confirmation dialog or confirmation page)
3. Only the owner can delete their QR code — deleting another user's code returns 404
4. After successful deletion, user is redirected to My QR Codes list with a success message
5. Deleted QR code is permanently removed from the database
6. Anti-forgery token is required on the delete POST action
7. Deletion event is logged

## Dev Notes
### Routes (from Architecture §3.6)
- POST /QRCodes/Delete/{id} — Delete a QR code (confirmation required)

### Security
- Verify QRCode.UserId == current user's ID before deleting
- Anti-forgery token required (use Html.AntiForgeryToken() in form)
- Return NotFound to avoid revealing other users' data

### Architecture Note
- QR codes are immutable: only create, read, delete — no edit operations (Architecture §3.5)
- Cascade delete is configured: if a user is deleted, their QR codes are also deleted

### Testing
- Test delete own QR code → removed from database, redirect with success
- Test delete another user's QR code → 404
- Test delete non-existent QR code → 404
- Test delete without anti-forgery token → 400
- Test confirmation is required before delete
- Verify QR code no longer appears in list after deletion
