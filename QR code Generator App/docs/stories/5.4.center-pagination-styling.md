# Story 5.4: Center & Style Pagination Controls

## Status
Not Started

## Story
**As a** user,
**I want** the pagination controls on the QR Codes list page to be centered and styled consistently with other action buttons on the page,
**so that** the UI has a more polished appearance and the pagination is more visually prominent and accessible.

## Acceptance Criteria
1. The pagination navigation is horizontally centered on the page
2. The pagination styling matches the "View Details" button styling (btn btn-outline-primary)
3. The pagination controls maintain responsive behavior on mobile devices
4. The active page number is clearly distinguished from other page numbers
5. Previous/Next buttons are properly styled and aligned
6. The pagination maintains proper accessibility (aria labels)
7. The pagination container has appropriate margins/spacing from surrounding content

## Tasks / Subtasks
- [ ] Wrap pagination `<nav>` element in a center-aligned container
- [ ] Add Bootstrap flexbox classes to center the pagination (d-flex justify-content-center)
- [ ] Update pagination styling to use btn btn-outline-primary classes
- [ ] Apply custom CSS if needed to match button styling precisely
- [ ] Test pagination display on different screen sizes
- [ ] Verify active page highlight is visible and clear
- [ ] Verify Previous/Next page navigation still works
- [ ] Test with multiple pages to ensure pagination displays correctly
