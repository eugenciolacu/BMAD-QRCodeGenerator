# Story 4.2: Download QR Code as Image (SVG/PNG)

## Status
Done

## Story
**As an** authenticated user,
**I want** to download a QR code as an SVG or PNG image,
**so that** I can use it in digital documents, presentations, or other workflows.

## Acceptance Criteria
1. Download Image button is available on the QR Code Details page and "My QR Codes" page
2. User can choose format: SVG or PNG (via query parameter or UI toggle)
3. Image is generated on demand (not stored in database)
4. Downloaded file has a meaningful filename (e.g., qrcode-{id}.svg or qrcode-{id}.png)
5. Only the owner can download — unauthorized access returns 404
6. Content-Disposition header is set for download
7. Image generation completes in under 1 second

## Tasks / Subtasks
- [x] Create DownloadImage action in QRCodesController (AC: 1, 5, 6)
  - [x] GET /QRCodes/DownloadImage/{id}?format=svg|png — verify ownership, generate, return FileResult
  - [x] Return NotFound if not found or not owned
  - [x] Default format: SVG
- [x] Generate QR code image via QRCodeService (AC: 3)
  - [x] Method: GenerateImage(text, ecc, version, format) → byte[]
  - [x] SVG output: use library's SVG generation
  - [x] PNG output: convert SVG to PNG or use library's bitmap generation
- [x] Set Content-Disposition and content type headers (AC: 4, 6)
  - [x] SVG: Content-Type: image/svg+xml
  - [x] PNG: Content-Type: image/png
- [x] Add format selection to Details page UI (AC: 2)
  - [x] Dropdown or toggle to select SVG/PNG before download
- [x] Add [Authorize] attribute (AC: 5)

## Dev Notes
### Routes (from Architecture §3.6)
- GET /QRCodes/DownloadImage/{id}?format=svg|png — Generate and download QR code image (on demand)

### Image Generation
- SVG: preferred for scalability and print quality
- PNG: for compatibility with systems that don't support SVG
- Both generated from stored parameters using Net.Codecrete.QrCodeGenerator

### Security
- Validate ownership before serving image
- Return NotFound for unauthorized access

### Testing
- Test SVG download for owned QR code → valid SVG file
- Test PNG download for owned QR code → valid PNG file
- Test download without format → defaults to SVG
- Test download for another user's QR code → 404
- Test download for non-existent QR code → 404
- Verify downloaded images are scannable/valid QR codes
