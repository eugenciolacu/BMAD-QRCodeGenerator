# Story 2.4: Email Sender Service for Registration Confirmation

## Status
Done

## Story
**As a** developer,
**I want** to implement an email sender service using a Gmail account,
**so that** the application can send registration confirmation emails to users.

## Acceptance Criteria
1. Implement a simple email sender service that can send emails via a configured Gmail account (SMTP).
2. Register EmailSender service with dependency injection in Program.cs.
3. Update the registration process to send a confirmation email using ASP.NET Core Identity's confirmation mechanism.
4. Email content for registration confirmation must include a secure confirmation link generated by Identity.
5. Update registration to require email confirmation (RequireConfirmedAccount = true).
6. Email sender credentials and settings must be stored securely in appsettings.json (do not hardcode).
7. Provide clear error handling and logging for email sending failures.
8. Update documentation to describe configuration steps for the email sender service.
9. All new and updated code must be covered by tests (unit or integration as appropriate).

## Tasks / Subtasks
- [x] Implement EmailSender service (IEmailSender implementation)
- [x] Configure Gmail SMTP settings in appsettings.json

## Implementation Notes
- Use ASP.NET Core Identity's built-in support for email confirmation.
- Use dependency injection for the email sender service.
- Gmail SMTP may require enabling "App Passwords" or "Less secure app access" (document this for devs).
- Ensure no sensitive credentials are committed to source control.
