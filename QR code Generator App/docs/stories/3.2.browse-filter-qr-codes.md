# Story 3.2: Browse & Filter QR Codes

## Status
Done

## Story
**As an** authenticated user,
**I want** to browse and filter my QR codes in a paginated list,
**so that** I can easily find and manage my stored QR codes.

## Acceptance Criteria
1. "My QR Codes" page is accessible from Dashboard and navigation
2. Page displays a table/grid of the current user's QR codes only
3. Each row shows: DecodedText, ECC Level, QR Version, CreatedAt, Notes
4. List is paginated (e.g., 10 items per page)
5. User can filter/search by DecodedText
6. List is sorted by CreatedAt descending (newest first) by default
7. View Details, Download PDF, and Delete buttons are displayed above or below the table/grid. When a row is selected, these buttons become interactable and perform actions for the selected QR code. Delete functionality is implemented as described in Story 3.4.
8. Empty state: clear message when user has no QR codes, with link to Create
9. Only the authenticated user's QR codes are shown (data isolation enforced)
10. Page matches front-end spec wireframe: table with filters, search, pagination, Bootstrap 5

## Dev Notes
### Routes (from Architecture §3.6)
- GET /QRCodes — List all QR codes for current user

### Data Isolation (from Architecture §6)
- ALWAYS filter by current user's ID
- Never expose other users' data

### Wireframe (from Front-End Spec)
- Header + Navigation
- Table/Grid with Filters and Search bar
- Pagination controls
- Row selection → View Details or Download PDF buttons

### Query Pattern
```csharp
var qrCodes = await _context.QRCodes
    .Where(q => q.UserId == currentUserId)
    .Where(q => string.IsNullOrEmpty(search) || q.DecodedText.Contains(search))
    .OrderByDescending(q => q.CreatedAt)
    .Skip((page - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();
```
