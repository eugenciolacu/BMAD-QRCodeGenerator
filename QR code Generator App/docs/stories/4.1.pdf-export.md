# Story 4.1: Download QR Code as PDF

## Status
Done

## Story
**As an** authenticated user,
**I want** to download a QR code as a PDF with embedded SVG,
**so that** I can print it for physical deployment in AR/VR workflows.

## Acceptance Criteria
1. Download PDF button is available on the QR Code Details page and "My QR Codes" page
2. PDF is generated on demand using QuestPDF (not pre-stored)
3. PDF contains the QR code rendered as SVG
4. PDF includes metadata: DecodedText, ECC Level, QR Version, Created Date
5. PDF has a clean, professional layout
6. Downloaded file has a meaningful filename (e.g., qrcode-{id}.pdf)
7. Only the owner can download their QR code PDF — unauthorized access returns 404
8. PDF generation completes in under 1 second for typical input
9. Content-Disposition header is set for file download

## Dev Notes
### Routes (from Architecture §3.6)
- GET /QRCodes/DownloadPdf/{id} — Generate and download PDF (on demand, not stored)

### PDF Generation (from Architecture §4.3)
- Library: QuestPDF
- PDF is generated server-side on each request — not cached or stored
- QR code is rendered as SVG and embedded in the PDF
- Note: QuestPDF Community license is free for companies with < $1M annual revenue

### QuestPDF Example Pattern
```csharp
Document.Create(container =>
{
    container.Page(page =>
    {
        page.Size(PageSizes.A4);
        page.Margin(2, Unit.Centimetre);
        page.Header().Text("QR Code").FontSize(20);
        page.Content().Column(col =>
        {
            col.Item().Image(qrImageBytes);
            col.Item().Text($"Text: {qrCode.DecodedText}");
            col.Item().Text($"ECC: {qrCode.ErrorCorrectionLevel}");
            col.Item().Text($"Version: {qrCode.QRVersion}");
            col.Item().Text($"Created: {qrCode.CreatedAt:yyyy-MM-dd}");
        });
    });
}).GeneratePdf(stream);
```

### Security
- Validate ownership before generating PDF
- Return NotFound for unauthorized access

### Testing
- Test PDF download for owned QR code → valid PDF file returned
- Test PDF contains correct QR code image and metadata
- Test PDF download for another user's QR code → 404
- Test PDF download for non-existent QR code → 404
- Test PDF filename is meaningful
- Test performance: generation < 1 second
