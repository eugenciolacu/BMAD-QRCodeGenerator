# Story 2.2: User Login & Logout

## Status
Done

## Story
**As a** registered user,
**I want** to log in to the application and log out when finished,
**so that** I can securely access my QR codes and protect my session.

## Acceptance Criteria
1. Login page is accessible from the landing page via "Login" link
2. Login form requires email and password
3. Successful login redirects to Dashboard
4. Invalid credentials show a clear, generic error message (do not reveal which field is wrong)
5. All inputs validated client-side and server-side
6. Logout action invalidates session and redirects to landing/login page
7. Logout is available from the navigation bar on all authenticated pages
8. Failed login attempts are logged
9. Session timeout is configured (reasonable duration, e.g., 30 minutes)
10. Page matches front-end spec wireframe: centered form, Bootstrap 5, "Forgot Password" and "Register" links

## Dev Notes
### Routes (from Architecture §3.6)
- GET /Account/Login — Show login form
- POST /Account/Login — Submit login
- POST /Account/Logout — Log out user

### Wireframe (from Front-End Spec)
- Header: App Name
- Centered form: Email, Password, Login button, Register link, Forgot Password link

### Security (from Architecture §6)
- Generic error on failed login ("Invalid login attempt") — never reveal if email exists
- Anti-forgery tokens on POST
- Log authentication events (login success, failure, logout)
- Session invalidation on logout and password change
- Secure cookies: HttpOnly, Secure, SameSite

### Session Configuration
- Cookie expiration: 30 minutes sliding
- Invalidate on logout

### Testing
- Test login with valid credentials → redirect to Dashboard
- Test login with invalid password → generic error
- Test login with non-existent email → same generic error
- Test logout → session invalidated, redirect to login
- Test session timeout → redirect to login after inactivity
- Verify logout button appears on all authenticated pages

## Implementation Notes (2026-02-17)
Login and logout functionality implemented using ASP.NET Core Identity Framework scaffolding:
- Login and logout logic handled by Razor Pages under /Identity/Account/ (Login.cshtml, Login.cshtml.cs, Logout.cshtml.cs)
- Endpoints:
  - GET /Identity/Account/Login — Show login form
  - POST /Identity/Account/Login — Submit login
  - POST /Identity/Account/Logout — Log out user
- Failed login attempts logged for security monitoring
- Session timeout configured to 30 minutes sliding expiration
- Secure cookies (HttpOnly, Secure, SameSite=Strict) and anti-forgery tokens enforced globally
- UI customized to match front-end spec (Bootstrap 5, centered card layout)
- Logout button conditionally displayed in navigation based on authentication state
