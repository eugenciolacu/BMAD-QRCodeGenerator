# Story 3.3: View QR Code Details

## Status
Done

## Story
**As an** authenticated user,
**I want** to view the full details and preview of a specific QR code,
**so that** I can verify its content and access download options.

## Acceptance Criteria
1. Details page is accessible from the QR codes list (click View Details)
2. Page displays all QR code metadata: DecodedText, ECC Level, QR Version, CreatedAt, Notes
3. Page displays a rendered QR code preview (generated on-the-fly from stored parameters)
4. Page includes Download PDF, Download Image, and Delete buttons
5. Page includes a "Back to My QR Codes" link
6. Delete button is present next to Download PDF and Download Image. Delete functionality is implemented as described in Story 3.4.
6. User can only view their own QR codes — accessing another user's QR code returns 404 or 403
7. Non-existent QR code ID returns 404
8. Page matches front-end spec wireframe: card layout, Bootstrap 5

## Dev Notes
### Routes (from Architecture §3.6)
- GET /QRCodes/Details/{id} — Show details for a single QR code (only if owned by user)

### Data Isolation
- Verify QRCode.UserId == current user's ID before displaying
- Return NotFound (not Forbidden) to avoid revealing existence of other users' data

### QR Code Preview
- Use Net.Codecrete.QrCodeGenerator to regenerate the QR code from stored parameters
- Render as PNG inline or as base64-encoded PNG <img> tag
- QR code is NOT stored as an image — always regenerated from parameters

### Wireframe (from Front-End Spec)
- Header + Navigation
- QR Code Details Card: Preview, Data fields, Download PDF button, Download Image button, Back link

### Testing
- Test details page with valid owned QR code → displays all fields + preview
- Test details page with another user's QR code → 404
- Test details page with non-existent ID → 404
- Test download buttons are present and link correctly
- Test back link navigates to QR codes list
