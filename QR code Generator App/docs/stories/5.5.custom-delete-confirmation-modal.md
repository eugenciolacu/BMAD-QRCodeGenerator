# Story 5.5: Replace Native Alert with Bootstrap 5 Delete Confirmation Modal

## Status
Done

## Story
**As a** user,
**I want** to see a styled Bootstrap 5 confirmation modal when deleting a QR code,
**so that** the confirmation experience is consistent with the app's design and provides better UX.

## Acceptance Criteria
1. Delete confirmation uses a Bootstrap 5 modal instead of native `confirm()` dialog
2. Modal displays a clear warning message and details about the action
3. Modal has "Cancel" and "Delete" buttons with appropriate styling (danger for delete)
4. Modal can be closed by pressing Escape key or clicking outside the modal
5. Delete form submission is prevented until user confirms in the modal
6. Modal appears on both Details page and Index page (if delete buttons exist there)
7. No JavaScript inline event handlers are used; all interactions are unobtrusive

## Tasks / Subtasks
- [x] Create reusable modal component/partial
- [x] Update Details.cshtml to use Bootstrap modal instead of confirm()
- [x] Add JavaScript to handle modal interactions and form submission
- [x] Test modal functionality on both trigger points
- [x] Verify modal styling and accessibility

## Dev Notes
### Technical Approach
- Replace `onsubmit="return confirm(...)"` with modal trigger
- Use data attributes to link delete forms with modal
- Handle form submission via JavaScript with Bootstrap modal instance
- Utilize Bootstrap 5's modal component for consistency

### Implementation Details
- Modal ID: `deleteConfirmationModal`
- Form data attribute: `data-bs-target="#deleteConfirmationModal"`
- Leverage Bootstrap's modal JavaScript API (no additional JS library needed)

### Accessibility
- Proper ARIA labels for modal
- Keyboard support (Escape to close, Tab to navigate button)
- Clear action descriptions in modal body

## Testing
- Verify modal appears when delete button is clicked
- Verify modal can be closed with Cancel button, Escape key, or backdrop click
- Verify form is submitted only when Delete button in modal is clicked
- Verify modal styling matches Bootstrap 5 theme
- Test on QR Codes Details page
