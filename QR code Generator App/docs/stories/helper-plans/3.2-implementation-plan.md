## Step 2 — Create `QRCodesListViewModel`

**New file:** `Models/QRCodesListViewModel.cs`

This is the main ViewModel passed to the Index view. It holds the paged item list, active filter state, pagination metadata, and the two distinct empty-state flags.

```csharp
namespace QRCodeGeneratorApp.Models
{
    public class QRCodesListViewModel
    {
        // Items for the current page
        public List<QRCodeListItemViewModel> Items { get; set; } = new();

        // --- Filter / pagination state ---
        public string? Search { get; set; }
        public int Page { get; set; } = 1;
        public int PageSize { get; set; } = 10;
        public int TotalCount { get; set; }

        // --- Empty state flags ---
        // True when the user has NO QR codes at all (library is empty)
        public bool IsEmptyLibrary { get; set; }
        // True when the user has QR codes but the current search returned nothing
        public bool NoSearchResults { get; set; }
    }
}
```

## Step 3 — Upgrade `QRCodesController.Index()` Action

**File to edit:** `Controllers/QRCodesController.cs`

Replace the current stub `Index()` with a full implementation that:
- Accepts `search` and `page` query parameters
- Sources `currentUserId` from `HttpContext.User` only (never from query string)
- Applies `UserId` filter **first**, then the search predicate (SEC-001 / SEC-003)
- Uses **one shared `IQueryable`** for both `CountAsync()` and `ToListAsync()` so pagination metadata is always scoped correctly (SEC-003)
- Hardcodes `pageSize = 10` — never reads it from the request (PERF-001)
- Clamps `page` between 1 and `totalPages` (TECH-001)
- Maps `QRCode` entities to `QRCodeListItemViewModel` with truncated display strings
- Sets `IsEmptyLibrary` and `NoSearchResults` flags correctly (UX-001)
- Emits a structured log entry (OPS-001)

```csharp
// GET /QRCodes
[HttpGet]
public async Task<IActionResult> Index(string? search, int page = 1)
{
    const int pageSize = 10;
    const int truncateText = 40;
    const int truncateNotes = 60;

    var currentUserId = User.FindFirstValue(ClaimTypes.NameIdentifier)!;

    // --- Base query scoped to current user FIRST (SEC-001) ---
    var baseQuery = _context.QRCodes
        .Where(q => q.UserId == currentUserId);

    // Total count BEFORE search — used to detect IsEmptyLibrary
    var totalLibraryCount = await baseQuery.CountAsync();

    // Apply search predicate (server-side partial match on DecodedText)
    var filteredQuery = string.IsNullOrWhiteSpace(search)
        ? baseQuery
        : baseQuery.Where(q => q.DecodedText.Contains(search));

    // Count AFTER search — used for pagination metadata (SEC-003)
    var totalCount = await filteredQuery.CountAsync();
    int totalPages = totalCount == 0 ? 1 : (int)Math.Ceiling((double)totalCount / pageSize);

    // Clamp page to valid range (TECH-001)
    page = Math.Max(1, Math.Min(page, totalPages));

    // Fetch paged data
    var items = await filteredQuery
        .OrderByDescending(q => q.CreatedAt)
        .Skip((page - 1) * pageSize)
        .Take(pageSize)
        .ToListAsync();

    // Map to display ViewModel
    var viewItems = items.Select(q => new QRCodeListItemViewModel
    {
        Id = q.Id,
        DecodedText = q.DecodedText,
        DecodedTextDisplay = q.DecodedText.Length > truncateText
            ? q.DecodedText[..truncateText] + "…"
            : q.DecodedText,
        ErrorCorrectionLevel = q.ErrorCorrectionLevel,
        QRVersion = q.QRVersion,
        CreatedAt = q.CreatedAt,
        NotesDisplay = q.Notes == null ? string.Empty
            : q.Notes.Length > truncateNotes ? q.Notes[..truncateNotes] + "…"
            : q.Notes
    }).ToList();

    var vm = new QRCodesListViewModel
    {
        Items = viewItems,
        Search = search,
        Page = page,
        PageSize = pageSize,
        TotalCount = totalCount,
        IsEmptyLibrary = totalLibraryCount == 0,
        NoSearchResults = totalLibraryCount > 0 && totalCount == 0
    };

    _logger.LogInformation(
        "QR code list accessed. UserId={UserId} Search={Search} Page={Page} ResultCount={ResultCount}",
        currentUserId, search ?? string.Empty, page, totalCount);

    return View(vm);
}
```

> **Note:** `using Microsoft.EntityFrameworkCore;` must be present at the top of the controller file for `CountAsync()` and `ToListAsync()`.

**Manual test:** Navigate to `/QRCodes` while logged in. Page should load without errors and display your QR codes (or an empty state if you have none).

## Step 4 — Rebuild `Views/QRCodes/Index.cshtml`

**File to replace:** `Views/QRCodes/Index.cshtml`

Rebuild this view from scratch. The view must:
- Accept `@model QRCodeGeneratorApp.Models.QRCodesListViewModel`
- Render a Bootstrap 5 search form (GET method, preserves terms across pagination links)
- Render the three action buttons (View Details, Download PDF, Delete) — **disabled by default**; a `data-id` tracking variable is populated when a row is selected
- Render the Bootstrap 5 table with all 5 columns
- Handle both empty states distinctly
- Render pagination controls using the ViewModel metadata

```html
@model QRCodeGeneratorApp.Models.QRCodesListViewModel
@{
    ViewData["Title"] = "My QR Codes";
}

<h2 class="mb-4">My QR Codes</h2>

<!-- Search form (GET — preserves search term across pages) -->
<form method="get" asp-action="Index" class="row g-2 mb-3">
    <div class="col-auto">
        <input type="text"
               name="search"
               value="@Model.Search"
               class="form-control"
               placeholder="Search by content…"
               maxlength="100" />
    </div>
    <div class="col-auto">
        <button type="submit" class="btn btn-outline-primary">Search</button>
    </div>
    @if (!string.IsNullOrEmpty(Model.Search))
    {
        <div class="col-auto">
            <a asp-action="Index" class="btn btn-outline-secondary">Clear</a>
        </div>
    }
</form>

<!-- Action buttons — disabled until a row is selected -->
<div class="mb-3 d-flex gap-2">
    <a id="btn-details"
       class="btn btn-outline-primary disabled"
       aria-disabled="true"
       href="#">View Details</a>

    <a id="btn-pdf"
       class="btn btn-outline-success disabled"
       aria-disabled="true"
       href="#">Download PDF</a>

    <button id="btn-delete"
            class="btn btn-outline-danger"
            disabled
            type="button">Delete</button>
</div>

<!-- Table / empty states -->
@if (Model.IsEmptyLibrary)
{
    <div class="alert alert-info">
        You haven't created any QR codes yet.
        <a asp-controller="QRCodes" asp-action="Create" class="alert-link">Create your first one</a>.
    </div>
}
else if (Model.NoSearchResults)
{
    <div class="alert alert-warning">
        No QR codes match your search.
        <a asp-action="Index" class="alert-link">Clear search</a> to see all your QR codes.
    </div>
}
else
{
    <table class="table table-bordered table-hover" id="qr-table">
        <thead class="table-light">
            <tr>
                <th>Content</th>
                <th>ECC</th>
                <th>Version</th>
                <th>Created (UTC)</th>
                <th>Notes</th>
            </tr>
        </thead>
        <tbody>
            @foreach (var item in Model.Items)
            {
                <tr class="qr-row"
                    data-id="@item.Id"
                    data-details-url="@Url.Action("Details", "QRCodes", new { id = item.Id })"
                    data-pdf-url="@Url.Action("DownloadPdf", "QRCodes", new { id = item.Id })"
                    data-delete-url="@Url.Action("Delete", "QRCodes", new { id = item.Id })"
                    style="cursor:pointer;">
                    <td title="@item.DecodedText">@item.DecodedTextDisplay</td>
                    <td>@item.ErrorCorrectionLevel</td>
                    <td>@item.QRVersion</td>
                    <td>@item.CreatedAt.ToString("yyyy-MM-dd HH:mm")</td>
                    <td title="@item.NotesDisplay">@(string.IsNullOrEmpty(item.NotesDisplay) ? "—" : item.NotesDisplay)</td>
                </tr>
            }
        </tbody>
    </table>

    <!-- Pagination controls -->
    @if (Model.TotalPages > 1)
    {
        <nav aria-label="QR code list pagination">
            <ul class="pagination">
                <li class="page-item @(Model.Page <= 1 ? "disabled" : "")">
                    <a class="page-link"
                       asp-action="Index"
                       asp-route-search="@Model.Search"
                       asp-route-page="@(Model.Page - 1)">Previous</a>
                </li>

                @for (int p = 1; p <= Model.TotalPages; p++)
                {
                    <li class="page-item @(p == Model.Page ? "active" : "")">
                        <a class="page-link"
                           asp-action="Index"
                           asp-route-search="@Model.Search"
                           asp-route-page="@p">@p</a>
                    </li>
                }

                <li class="page-item @(Model.Page >= Model.TotalPages ? "disabled" : "")">
                    <a class="page-link"
                       asp-action="Index"
                       asp-route-search="@Model.Search"
                       asp-route-page="@(Model.Page + 1)">Next</a>
                </li>
            </ul>
        </nav>
    }

    <p class="text-muted small">
        Showing @Model.Items.Count of @Model.TotalCount result(s) — Page @Model.Page of @Model.TotalPages
    </p>
}

@section Scripts {
    <script>
        // Row selection logic
        let selectedId = null;

        document.querySelectorAll('.qr-row').forEach(function (row) {
            row.addEventListener('click', function () {
                // Deselect previous row
                document.querySelectorAll('.qr-row').forEach(r => r.classList.remove('table-active'));

                // Select clicked row
                row.classList.add('table-active');
                selectedId = row.getAttribute('data-id');

                const detailsUrl = row.getAttribute('data-details-url');
                const pdfUrl = row.getAttribute('data-pdf-url');
                const deleteUrl = row.getAttribute('data-delete-url');

                // Enable and wire action buttons
                const btnDetails = document.getElementById('btn-details');
                const btnPdf = document.getElementById('btn-pdf');
                const btnDelete = document.getElementById('btn-delete');

                btnDetails.classList.remove('disabled');
                btnDetails.removeAttribute('aria-disabled');
                btnDetails.href = detailsUrl;

                btnPdf.classList.remove('disabled');
                btnPdf.removeAttribute('aria-disabled');
                btnPdf.href = pdfUrl;

                btnDelete.removeAttribute('disabled');
                btnDelete.onclick = function () {
                    if (confirm('Are you sure you want to delete this QR code?')) {
                        // Submit a hidden form for the POST delete action (Story 3.4)
                        const form = document.getElementById('delete-form');
                        form.action = deleteUrl;
                        form.submit();
                    }
                };
            });
        });
    </script>

    <!-- Hidden form for DELETE POST (anti-forgery handled here) -->
    <form id="delete-form" method="post" style="display:none;">
        @Html.AntiForgeryToken()
    </form>
}
```

## Risk Flags to Keep in Mind

| Risk | What to watch | Where it is addressed |
|------|---------------|----------------------|
| SEC-001 | UserId filter is the FIRST `.Where()` clause — never skip it | Step 3 controller code |
| SEC-003 | Count query uses the same `filteredQuery` variable as data query | Step 3 (`totalCount` from `filteredQuery`) |
| SEC-004 | `Details`, `DownloadPdf`, `Delete` controller actions must each verify `UserId == currentUserId` — those are Stories 3.3, 3.4, 4.1 | Out of scope here; flagged |
| SEC-005 | Razor auto-encodes `@Model.Search` in HTML attributes — never use `Html.Raw` with search term | Step 4 view (no `Html.Raw` used) |
| PERF-001 | `pageSize` is hardcoded as `const int pageSize = 10` — never read from query string | Step 3 |
| UX-001 | Two empty state branches: `IsEmptyLibrary` vs `NoSearchResults` | Step 3 (ViewModel flags) + Step 4 (view branches) |
